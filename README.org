#+title: Readme


* To use:
0. Have Stow and git installed; And, of course, each package as well;

1. Git clone it (cd then 'git clone url')
   #+begin_src bash
    cd
    git clone https://github.com/wil3212/dotfiles.git
   #+end_src
2. Navigate to the directory (default to ~/dotfiles, or simply 'cd ~/dotfiles' from anywhere)
    #+begin_src bash
    cd ~/dotfiles
    #+end_src
3. To get *all* the configs, simply:
    #+begin_src bash
    stow */
    #+end_src
4. If you wanna just some particular pkg config, say 'nvim':
   #+begin_src bash
    stow nvim
   #+end_src



* Currently includes configs for:
1. doom
2. foot
3. nvim
4. starship
5. sway
6. waybar

(In case you use Arch and wanna install all of these, except doom...,:
#+begin_src bash
 sudo pacman -S foot nvim starship sway waybar
 sudo pacman -S ttf-font-awesome ttf-jetbrains-mono-nerd noto-fonts-emoji
#+end_src


* Useful commands:
1. Removes symlinks created by Stow (cd ~/dotfiles first):
#+begin_src
    stow -D .
    fc-cache -fv
#+end_src
